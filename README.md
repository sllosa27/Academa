# Academa

Academa is a student productivity app that helps students organize their assignments and automatically break down upcoming deadlines into practical study sessions.

#Features 

- Add assignments with due dates and priority levels
- Add assignments with due dates and priority levels
- Automatically generate 3 study sessions before a deadline
- Save assignments using browser storage
- Mark assignments as completed
- Delete assignments
- Responsive, student-friendly interface

## Tech Stack

- React
- JavaScript
- CSS
- LocalStorage
- Vite

## How It Works

1. Add an assignment with a due date and priority.
2. Academa saves the assignment in the browser.
3. Generate Study Sessions creates three sessions leading up to the deadline.
4. Complete or delete assignments as you progress.

## Purpose

Academa was built to help students avoid last minute studying by turning upcoming assignments into smaller, manageable study sessions.
